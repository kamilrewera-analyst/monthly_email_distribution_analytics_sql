# Monthly Email Distribution & Account Activity Analytics

This repository contains a CTE-based SQL query designed to analyze monthly email distribution patterns per account without relying on nested subqueries.

## Overview & Objectives

The goal of this query is to evaluate account-level email volume contributions relative to total monthly email activity, alongside tracking key account interaction timestamps.

Key analytical focus areas:
*   **Monthly Percentage Contribution:** Calculating the percentage share of emails sent by each individual account relative to all emails sent in that given month (`sent_msg_percent_from_this_month`).
*   **Activity Range Tracking:** Identifying the exact date of the first (`first_sent_date`) and last (`last_sent_date`) email sent by each account within every month.
*   **Refactoring via CTEs:** Structuring logic with Common Table Expressions (CTEs) for clean readability instead of subqueries.

---

## SQL Pipeline Architecture

The query consists of a 2-step CTE execution flow:

1.  `mails_by_month`: Extracts and calculates the actual sent dates by joining sessions with message logs, truncating sent dates to the first day of the month (`sent_month`).
2.  `mials_sent_date`: Employs window functions (`COUNT() OVER()`, `MIN() OVER()`, `MAX() OVER()`) to compute relative monthly email volume percentages and log the earliest/latest interaction per account.
3.  **Final Query:** Selects unique account-month rows (`SELECT DISTINCT`), ordering the results chronologically by `sent_month` in descending order.

---

## Tech Stack & Key Concepts

*   **Query Language:** SQL (Google BigQuery dialect)
*   **Advanced SQL Concepts:**
    *   Common Table Expressions (CTEs)
    *   Window Functions (`COUNT() OVER (PARTITION BY ...)` for proportional share)
    *   Analytical Aggregate Windows (`MIN() OVER ()`, `MAX() OVER ()`)
    *   Date Manipulation (`DATE_ADD`, `EXTRACT`, `DATE`)
    *   Result Deduplication (`SELECT DISTINCT`)
